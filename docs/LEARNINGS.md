### Repo / branches

- This repo uses squash merges, so `git branch --merged main` misses merged branches. Cross-check with `gh pr list --state all` and `git cherry main <branch>`; squash-merged branches need `git branch -D` (blocked by a local hook — delete manually).

### iOS / Expo device builds
- The project uses CNG (Continuous Native Generation): `ios/` is generated by `npx expo prebuild` and is git-ignored (`/ios/` in `.gitignore`). Never commit it; regenerate with `npx expo prebuild --platform ios --clean` when config changes.
- The app needs a dev build (expo-sqlite, expo-secure-store, react-native-maps) — Expo Go will not work. Use `npx expo run:ios --device`.
- Device detection: `xcrun devicectl list devices` (Liz iPhone, iPhone 15 Pro, UDID `00008130-000874420083401C`) — it shows up when connected/paired.
- Blocker found: `security find-identity -v -p codesigning` returned 0 identities and no Apple ID team is configured in Xcode. A free personal Apple ID team is enough for dev builds, but signing in to Xcode is a one-time manual step (Xcode > Settings > Accounts).
- After signing is set up once, the working command is:
  `npx expo run:ios --device` (pick "Liz iPhone" from the list).

### Non-interactive signing setup (2026-07-03, later session)
- After signing into Xcode, the personal team ID is NOT in `IDEProvisioningTeams`; it gets cached in `~/Library/Preferences/com.apple.dt.xcodebuild.plist` under `IDEProvisioningTeamByIdentifier` after any `xcodebuild -allowProvisioningUpdates` run. Liz's personal team ID: `3933642U9H`.
- Expo supports `ios.appleTeamId` in app.config.ts — set it and re-run `npx expo prebuild --platform ios` to write `DEVELOPMENT_TEAM` into the pbxproj. Then `xcodebuild ... -allowProvisioningUpdates -allowProvisioningDeviceRegistration` creates the dev certificate and provisioning profile with no GUI interaction.
- Expo's `run:ios` pre-check fails with "No code signing certificates" until a cert exists; bootstrap the cert once via raw `xcodebuild -allowProvisioningUpdates`, after which `expo run:ios --device` works.
- First install on the phone is blocked until the user trusts the developer cert: Settings > General > VPN & Device Management > Developer App > Trust. Developer Mode (Settings > Privacy & Security) may also prompt on first launch.
- End state that works: app installed and running on the iPhone, Metro (`npx expo start`) serving the JS bundle over Wi-Fi. Free-tier provisioning profile expires after 7 days — rerun `npx expo run:ios --device` to re-sign when the app stops opening.
- Day-to-day loop: phone and Mac on the same Wi-Fi, run `npx expo start` in the repo, tap the trip-os icon. Full rebuild only needed when native deps or app.config.ts change.
